# Hi, I'm Morgan 👋

I'm a Manufacturing and Robotics Engineering student focused on building integrated systems where electronics, software, mechanical design, fabrication, and control come together.

I enjoy the full process of creation: from the first idea and system logic to the final prototype, testing, documentation, and improvement. I like projects where code has a tangible impact, whether it is controlling hardware, managing data, serving a web interface, or helping a mechanism behave the way it was designed to.

## About me

- Manufacturing and Robotics Engineering student
- I complement my university education with platforms like CS50 and DataCamp
- Interested in robotics, automation, electronics, embedded systems, and control
- I use full-stack development to create interfaces, databases, and tools for engineering projects.
- I enjoy connecting mechanical design, circuits, software, and fabrication into complete systems
- I like building, testing, documenting, improving, and understanding how things work
- I work with digital fabrication processes such as 3D printing, PCB fabrication, CNC milling, laser processes, and CAD/CAM workflows
- Linux user and open-source enthusiast
- Always learning through real projects, experiments, mistakes, and iteration

## Main areas

### Integrated engineering

I like working on projects that combine multiple disciplines instead of focusing on only one area. My goal is to build complete systems where hardware, software, design, and manufacturing work together.

### Electronics and embedded systems

I enjoy electronics when it becomes part of a larger system: circuits that interact with code, embedded logic, power and control stages, PCB design, signal processing, and hardware-software communication.

### Software for physical systems

I like writing software that connects with real devices or supports engineering projects. This includes full-stack applications, Python tools, Web interfaces, serial communication, SQL databases, computer vision, and systems for monitoring, controlling, or documenting hardware behavior.

### Design and fabrication

I use CAD/CAM workflows and digital fabrication as part of the engineering process. 3D printing, PCB fabrication, CNC milling, and laser processes are tools I use to turn ideas into functional prototypes.
